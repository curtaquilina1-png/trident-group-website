# Trident Group Solutions website

Official multi-page website source for Trident Group Solutions Malta and the domain `tridentgroupmt.com`.

## Preview locally

Run `python3 -m http.server 4173`, then open `http://localhost:4173`.

## Verify

Run `npm test`.

## Content updates

- Edit page copy in `scripts/generate-pages.mjs`, then run `node scripts/generate-pages.mjs`.
- Shared design and interaction files are in `assets/`.
- Add approved, anonymised project media under `assets/media/`.
- Replace the bracketed launch placeholders only with verified information.

## Before public launch

Confirm contact/legal details, logo and project-media consent; connect secure form delivery, file uploads and spam protection; configure consent-aware analytics; review privacy/cookie/terms drafts; enable GitHub Pages; and connect the custom domain.
